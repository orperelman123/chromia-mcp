# SQL to Rell Translation Guide

This guide demonstrates how to translate common SQL queries into Rell syntax, with real examples from a theater management system showing how Rell code is translated to SQL.

## Basic Entity Structure

In our theater system, we have the following main entities (similar to SQL tables):

```rell
entity play {
    name: text;
    description: text;
    genre: play_genre;
    duration_minutes: integer;
    key name;
}

entity theater_hall {
    name: text;
    capacity: integer;
    key name;
}

entity seat {
    theater: theater_hall;
    number: integer;
    category: seat_category;
    price: decimal;
    key theater, number;
}

entity booking {
    performance;
    seat;
    user_pubkey: byte_array;
    timestamp: integer;
    status: booking_status;
    key performance, seat;
}
```

## Basic SELECT Translations

### 1. Simple SELECT with JOIN

Rell:
```rell
seat @* {
    .theater.name == theater_name,
    .number == seat_number
}
```

Generated SQL:
```sql
SELECT A00."rowid"
FROM "c0.seat" A00
JOIN "c0.theater_hall" A01 ON A00."theater" = A01."rowid"
WHERE (A01."name" = ?) AND (A00."number" = ?)
```

### 2. Multiple JOINs with Complex Conditions

Rell:
```rell
performance @* {
    .play.name == play_name,
    .theater.name == theater_name,
    .timestamp == timestamp
}
```

Generated SQL:
```sql
SELECT A00."rowid"
FROM "c0.performance" A00
JOIN "c0.play" A01 ON A00."play" = A01."rowid"
JOIN "c0.theater_hall" A02 ON A00."theater" = A02."rowid"
WHERE ((A01."name" = ?) AND (A02."name" = ?)) AND (A00."timestamp" = ?)
```

### 3. Aggregation and Grouping

Rell supports several aggregation functions and unique value collection:

- `@sum` - Calculate sum of values
- `@count` - Count number of records
- `@min` - Get minimum value
- `@max` - Get maximum value
- `@+` - Get unique values (similar to SQL DISTINCT)

Rell:
```rell
// Basic aggregation
booking @* {
    .status == booking_status.CONFIRMED
} (
    play_name = .performance.play.name,
    total_revenue = @sum .seat.price,
    booking_count = @count *
)

// Getting unique values
booking @* {
    .status == booking_status.CONFIRMED
} (
    play_name = .performance.play.name,
    unique_categories = .seat.category @+ {}
)
```

Generated SQL:
```sql
-- Basic aggregation
SELECT
    A01."name" as play_name,
    SUM(A02."price") as total_revenue,
    COUNT(*) as booking_count
FROM "c0.booking" A00
JOIN "c0.performance" A03 ON A00."performance" = A03."rowid"
JOIN "c0.play" A01 ON A03."play" = A01."rowid"
JOIN "c0.seat" A02 ON A00."seat" = A02."rowid"
WHERE A00."status" = ?
GROUP BY A01."name"

-- Unique values
SELECT
    A01."name" as play_name,
    ARRAY_AGG(DISTINCT A02."category") as unique_categories
FROM "c0.booking" A00
JOIN "c0.performance" A03 ON A00."performance" = A03."rowid"
JOIN "c0.play" A01 ON A03."play" = A01."rowid"
JOIN "c0.seat" A02 ON A00."seat" = A02."rowid"
WHERE A00."status" = ?
GROUP BY A01."name"
```

### 4. Subqueries and EXISTS

Rell:
```rell
seat @* {
    exists(performance @* { .theater == seat.theater })
}
```

Generated SQL:
```sql
SELECT A00."rowid"
FROM "c0.seat" A00
WHERE EXISTS (
    SELECT 1
    FROM "c0.performance" A01
    WHERE A01."theater" = A00."theater"
)
```

### 5. Sorting and Limiting

Rell:
```rell
play @* {} (
    name = .name,
    total_bookings = @count booking @* { .performance.play == play }
) @* {} (
    @sort_desc total_bookings,
    @sort name
) limit 10
```

Generated SQL:
```sql
WITH cte AS (
    SELECT A00."name",
           COUNT(A01."rowid") as total_bookings
    FROM "c0.play" A00
    LEFT JOIN "c0.performance" A02 ON A02."play" = A00."rowid"
    LEFT JOIN "c0.booking" A01 ON A01."performance" = A02."rowid"
    GROUP BY A00."name"
)
SELECT *
FROM cte
ORDER BY total_bookings DESC, name ASC
LIMIT 10
```

## Special Query Attributes

### 1. @inner vs @outer Join

Rell:
```rell
// Inner join (default)
play @* {} (
    name = .name,
    performances = performance @* { .play == play }
)

// Outer join
play @* {} (
    name = .name,
    performances = @outer performance @* { .play == play }
)
```

Generated SQL:
```sql
-- Inner join
SELECT A00."name", A01."rowid"
FROM "c0.play" A00
JOIN "c0.performance" A01 ON A01."play" = A00."rowid"

-- Outer join
SELECT A00."name", A01."rowid"
FROM "c0.play" A00
LEFT JOIN "c0.performance" A01 ON A01."play" = A00."rowid"
```

### 2. @omit for Field Exclusion

Rell:
```rell
play @* {} (
    .name,
    .genre,
    @omit .description
)
```

Generated SQL:
```sql
SELECT A00."name", A00."genre"
FROM "c0.play" A00
```

### 3. @required for Non-null Constraints

Rell:
```rell
play @* {} (
    name = .name,
    @required latest_performance = performance @? {
        .play == play
    } (@sort_desc .timestamp)
)
```

Generated SQL:
```sql
SELECT A00."name", A01."rowid"
FROM "c0.play" A00
JOIN "c0.performance" A01 ON A01."play" = A00."rowid"
WHERE A01."rowid" IN (
    SELECT A02."rowid"
    FROM "c0.performance" A02
    WHERE A02."play" = A00."rowid"
    ORDER BY A02."timestamp" DESC
    LIMIT 1
)
```

## Best Practices

1. Use appropriate attributes:
   - `@inner` (default) for required relationships
   - `@outer` for optional relationships
   - `@omit` to exclude unnecessary fields
   - `@required` to enforce non-null constraints

2. Leverage Rell's automatic join handling:
   - Use dot notation (`.theater.name`) for natural joins
   - Rell automatically generates optimal join conditions

3. Use aggregation attributes effectively:
   - `@sum`, `@count`, `@avg` for calculations
   - `@group` for grouping operations
   - `@sort` and `@sort_desc` for ordering

4. Optimize query performance:
   - Use appropriate indexes (key declarations)
   - Filter early in the query chain
   - Use limit when possible to reduce result set size

## Common Patterns

1. Finding records by related entity attributes:
```rell
booking @* {
    .performance.play.name == "Hamlet",
    .seat.category == seat_category.VIP
}
```

2. Aggregating with multiple grouping criteria:
```rell
booking @* {} (
    @group theater = .performance.theater.name,
    @group category = .seat.category,
    total_revenue = @sum .seat.price
)
```

3. Complex sorting with multiple criteria:
```rell
performance @* {} (
    @sort_desc .timestamp,
    @sort .theater.name,
    @sort .play.name
)
```

4. Conditional aggregation:
```rell
theater_hall @* {} (
    name = .name,
    vip_seats = @count seat @* {
        .theater == theater_hall,
        .category == seat_category.VIP
    }
)
```
